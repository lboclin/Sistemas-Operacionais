# Registros de decisões (ADRs)

Crie uma ADR curta ao fechar uma decisão que impacte múltiplos módulos. Numere `0001-titulo.md` e registre contexto, alternativas, decisão, consequências, validação e data. O arquivo [DECISIONS.md](../DECISIONS.md) acompanha decisões ainda abertas.
